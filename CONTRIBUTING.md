# Contributing to OptiFlow

Thanks for your interest! OptiFlow is a local-first wellness app built with honesty about what is and isn't validated. Contributions that respect that principle are welcome.

## How to contribute

1. **Fork** the repository
2. **Create a branch** from `main`: `git checkout -b feature/your-feature`
3. **Make your changes** with clear, focused commits
4. **Test**: `npm test` and `npm run build` should pass
5. **Open a pull request** describing what changed and why

## Principles to keep in mind

- **No overclaiming.** Never add language that suggests OptiFlow diagnoses, treats, or detects medical conditions.
- **Privacy first.** No raw video uploads, no microphone access, no hidden tracking.
- **Local-first.** Features should work offline; cloud sync is optional.
- **Transparency.** If you add a score or metric, show how it's computed.

## Areas where help is especially welcome

- Improving the reset activity library
- Additional language translations
- Accessibility improvements (keyboard navigation, screen readers)
- Test coverage for camera and scoring modules
- Supabase migration polish

## Code style

- TypeScript strict mode
- Prettier formatting (2 spaces, semicolons)
- Descriptive commit messages (see existing history)
